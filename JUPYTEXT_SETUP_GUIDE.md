# Jupytext Notebook Workflow Setup Guide

This guide shows how to implement a dual-format notebook workflow using Jupytext, enabling both clean Git diffs and full Jupyter functionality.

## Overview

The workflow maintains notebooks in two formats:
- **Python files (`.py`)** - Source of truth for version control, provides clean diffs
- **Jupyter notebooks (`.ipynb`)** - Generated automatically, maintains rich outputs and interactivity

## Benefits

✅ **Clean Git diffs** - Python files show readable code changes, not JSON metadata  
✅ **Full Jupyter functionality** - Rich outputs, visualizations, interactive development  
✅ **Automated sync** - GitHub Actions automatically generates missing formats  
✅ **Better code review** - Reviewers see clean Python code instead of notebook JSON  

## Implementation Steps

### 1. Add Dependencies

Add to your `pyproject.toml` or `requirements.txt`:

```toml
# pyproject.toml
[project.optional-dependencies]
dev = [
    # ... other dev dependencies
    "jupytext>=1.15.0",
    "jupyter>=1.0.0",
]
```

### 2. Create Jupytext Configuration

Create `.jupytext.yml` in repository root:

```yaml
# Jupytext configuration
formats: "py:percent,ipynb"
notebook_metadata_filter: "all"
cell_metadata_filter: "-all"
```

### 3. Setup GitHub Actions Workflow

Create `.github/workflows/sync-notebooks.yaml`:

```yaml
name: Sync Notebooks

on:
  pull_request:
    branches: [ main ]
    paths: [ '**/*.py', '**/*.ipynb' ]

jobs:
  sync-notebooks:
    runs-on: ubuntu-latest
    permissions:
      contents: write
    
    steps:
    - name: Checkout repository
      uses: actions/checkout@v4
      with:
        fetch-depth: 0
        token: ${{ secrets.GITHUB_TOKEN }}

    - name: Set up Python
      uses: actions/setup-python@v4
      with:
        python-version: '3.11'

    - name: Install dependencies
      run: |
        pip install jupytext jupyter

    - name: Sync Python files to notebooks
      run: |
        # Convert .py files to .ipynb
        find . -name "*.py" -path "*/notebooks/*" -exec jupytext --to ipynb {} \\;

    - name: Sync notebooks to Python files
      run: |
        # Convert .ipynb files to .py (in case someone committed a notebook directly)
        find . -name "*.ipynb" -path "*/notebooks/*" -exec jupytext --to py:percent {} \\;

    - name: Check for changes
      id: verify-changed-files
      run: |
        if [ -n "$(git status --porcelain)" ]; then
          echo "changed=true" >> $GITHUB_OUTPUT
        else
          echo "changed=false" >> $GITHUB_OUTPUT
        fi

    - name: Commit and push changes to PR branch
      if: steps.verify-changed-files.outputs.changed == 'true'
      run: |
        git config --local user.email "action@github.com"
        git config --local user.name "GitHub Action"
        git add .
        git commit -m "Auto-sync notebooks and Python files" || exit 0
        git push origin HEAD:${{ github.head_ref }}
```

### 4. Update .gitignore

Add these rules to `.gitignore`:

```gitignore
# Jupyter Notebook
.ipynb_checkpoints/

# Don't ignore the generated notebooks in notebooks/ directory
# (we want both .py and .ipynb versions)
!notebooks/**/*.ipynb

# But ignore notebooks in other directories
*.ipynb
```

### 5. Convert Existing Notebooks

If you have existing `.ipynb` files:

```bash
# Install dependencies
pip install jupytext jupyter

# Convert existing notebooks to Python format
jupytext notebooks/your-notebook.ipynb --to py:percent

# The .ipynb file will be auto-generated by GitHub Actions
```

## Developer Workflow

### Primary Workflow (Recommended)

1. **Work with Python files**: Edit `notebooks/example.py`
2. **Use Jupyter cells format**:
   ```python
   # %% [markdown]
   # # My Notebook Title
   # This is a markdown cell

   # %%
   import pandas as pd
   # This is a code cell

   # %%
   data = pd.read_csv('data.csv')
   data.head()
   ```

3. **Commit Python files**: `git add notebooks/example.py`
4. **GitHub Actions handles the rest**: Automatically generates `.ipynb` during PR

### Testing Locally

```bash
# Convert Python to notebook for testing
jupytext --to ipynb notebooks/example.py

# Open in Jupyter
jupyter lab notebooks/example.ipynb

# Both files stay in sync automatically
```

## Repository Considerations

### Branch Protection Rules

If your repository has branch protection rules that prevent direct commits to main:

- ✅ **This workflow is compatible** - it only pushes to PR branches
- ✅ **No bypass rules needed** - workflow doesn't try to commit to protected branches
- ✅ **Works with existing rules** - respects all repository protection settings

### File Organization

Recommended structure:
```
your-repo/
├── .github/workflows/sync-notebooks.yaml
├── .jupytext.yml
├── .gitignore
├── notebooks/
│   ├── analysis/
│   │   ├── data_exploration.py
│   │   └── data_exploration.ipynb
│   └── examples/
│       ├── tutorial.py
│       └── tutorial.ipynb
└── pyproject.toml
```

## Troubleshooting

### Workflow Not Triggering

1. **Check file paths**: Workflow only triggers for files in `notebooks/` directory
2. **Verify permissions**: Ensure `contents: write` permission is set
3. **Check triggers**: Workflow only runs on PRs, not direct pushes to main

### Merge Conflicts

1. **Always resolve in Python files**: Edit the `.py` file to resolve conflicts
2. **Delete .ipynb if conflicted**: Let GitHub Actions regenerate it
3. **Use sync command**: `jupytext --sync notebooks/file.py` to update locally

### Missing Dependencies

If the workflow fails with import errors:
```bash
# Add dependencies to workflow or use uv/poetry
pip install jupytext jupyter
# Or in workflow:
# uv sync --extra dev
# uv run jupytext --to ipynb notebooks/*.py
```

## Advanced Configuration

### Custom Cell Types

```python
# %% tags=["parameters"]
# Parameter cells for papermill

# %% tags=["hide-input"]
# Hide input in reports
```

### Execution Control

```yaml
# .jupytext.yml
formats: "py:percent,ipynb"
notebook_metadata_filter: "all"
cell_metadata_filter: "-all"
execution:
  execute_notebooks: false
  timeout: 300
```

### Different Formats

```yaml
# Use different Python formats
formats: "py:light,ipynb"    # Minimal Python format
formats: "py:sphinx,ipynb"   # Sphinx-style format
formats: "py:percent,ipynb"  # Percent format (recommended)
```
