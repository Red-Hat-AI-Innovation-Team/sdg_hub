Installation

SDG Hub requires Python 3.10+ and can be installed from PyPI or from source for development.

Basic Installation

Install the core package with pip or uv:

pip install sdg-hub
# recommended
uv pip install sdg-hub

Or add it to an existing uv project:

uv init my-sdg-project
cd my-sdg-project
uv add sdg-hub

Optional Dependencies

SDG Hub defines several optional dependency groups for different use cases. Install them by appending the group name in brackets.

GroupPurposeInstall
dev Testing, linting, type checking pip install sdg-hub[dev]
examples Example notebooks and workflows pip install sdg-hub[examples]
docs Documentation building (MkDocs) pip install sdg-hub[docs]

Development Setup

For contributing to SDG Hub, clone the repo and install with development dependencies:

git clone https://github.com/Red-Hat-AI-Innovation-Team/sdg_hub.git
cd sdg_hub
uv sync --extra dev

Important: Always install pre-commit hooks after cloning. They enforce code formatting and commit message conventions.

uv run pre-commit install
uv run pre-commit install --hook-type commit-msg

Verify Installation

from sdg_hub import FlowRegistry, BlockRegistry

# Discover available components
FlowRegistry.discover_flows()
BlockRegistry.discover_blocks()

print(f"Flows: {len(FlowRegistry.list_flows())}")
print(f"Blocks: {len(BlockRegistry.list_blocks())}")
